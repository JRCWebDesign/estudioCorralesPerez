# Web del Estudio Corrales Perez

## Comandos

- npm install: instalar dependencias.
- npm run dev: iniciar preview local.
- npm run build: generar version de produccion en dist/client.

## Estructura

- src/App.jsx: componentes y contenido provisional.
- src/styles.css: identidad visual, animaciones y adaptacion responsive.
- public/assets/client-originals: capas originales entregadas por la clienta. Las letras recortadas conservan sus colores y forma.
- public/assets/hero-mobile-photo.png: foto vertical preparada para mobile.
- public/assets/hero-mobile-building.png: recorte transparente alineado con la foto vertical.

## Pendientes

Logo definitivo, presentacion del estudio, servicios detallados, contacto y finalidad de Mercado Pago. No hay cobros ni envios de formularios activos.

Fuentes: Bodoni Moda y Manrope desde Google Fonts. Iconos: Phosphor y Font Awesome para WhatsApp.

## Datos de contacto

Editar solo src/config/contacto.js para cambiar telefono, WhatsApp, mensaje inicial, Instagram, correo, direccion y horarios. Los enlaces se generan automaticamente y los datos vacios no se publican.
