# Estudio Corrales Perez

Preview institucional construida con React y Vite.

## Desarrollo

Desde la carpeta web:

```sh
npm install
npm run dev
```

## Compilacion

```sh
npm run build
```

Los archivos del sitio se generan en web/dist/client.

## Contenido

Portada con recursos originales, version vertical para celulares, navegacion y seis secciones provisionales. Los textos y datos de contacto pendientes estan marcados como a completar.

Se animan solo las letras. El edificio queda fijo y se respeta la preferencia de movimiento reducido. El icono de WhatsApp lleva a Contacto mientras no se confirme el numero.
